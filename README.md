# doa-winners

수지위너스 유치부 일정 공유 캘린더 (모바일 웹앱)

https://justinayuuu-ops.github.io/doa-winners/

## 처음 쓰는 순서

1. 앱을 열고 Firebase 실시간 데이터베이스 주소를 넣어 연결해요. 오늘도 도아 킥에서 쓰던 주소가 있으면 자동으로 채워져요.
2. 그 팀의 **첫 사용자가 관리자**로 등록돼요.
3. 관리자가 '팀' 탭에서 감독·코치 **초대 링크**를 만들어 보내요.
4. 감독·코치가 그룹(예: 7세 선수반, 7세 취미반)과 선수를 등록하고, 부모님에게 **가입 링크**를 보내요.
5. 그 밖의 사람은 가입할 때 **부모님 또는 선수**만 고를 수 있어요.

## 역할

| 역할 | 할 수 있는 일 |
|---|---|
| 관리자 | 모든 것 + 멤버 삭제, 관리자 넘기기 |
| 감독·코치 | 그룹·선수 등록, 그룹 일정 등록·변경·삭제, 공지 보내기, 멤버 초대·역할 변경, 선수 참석 체크 |
| 부모님·선수 | 우리 아이 그룹 일정 보기, 참여 응답(참석·불참·미정), 개인 일정(기기에만 저장) |

## 기능

- 정규 수업(매주 반복, 날짜별 휴강·변경), 대회·시합(단일 일정), 전체 휴강
- 카톡 공지 붙여넣기 → 장소·시간·준비물·당번 자동 채우기
- 공지 알림(앱 안 알림), 참여 응답 집계

## 데이터

팀 데이터는 Firebase 실시간 데이터베이스의 `<팀 이름>/` 아래에 저장돼요 (meta, users, invites, groups, players, events, notices, rsvp).
로그인 없이 기기별 계정 코드로 사람을 구분해요. 휴대폰을 바꾸면 '내 정보'의 계정 코드로 이어서 쓸 수 있어요.

`events.json`은 관리자 등록 때 한 번 불러오는 기본 일정이에요.
