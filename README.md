# doa-winners

수지위너스 유치부 일정 공유 캘린더 (모바일 웹앱)

- 정규 수업(매주 반복, 날짜별 휴강·변경), 대회·시합(단일 일정), 행사, 전체 휴강
- 역할: 관리자 / 감독·코치 / 부모님·선수
- 그룹(예: 7세 선수반, 7세 취미반)별 선수 등록, 그룹 대상 일정 + 공지 알림
- 참여 응답: 부모님·선수 응답, 감독·코치 본인 참여 + 선수 참석 체크
- 카톡 공지 붙여넣기 → 장소·시간·준비물·당번 자동 채우기
- 개인 일정은 각자 기기(localStorage)에만 저장

## 동작 방식

| 실행 위치 | 팀 일정 | 등록·수정·역할 관리 |
|---|---|---|
| claude.ai Artifact 링크 | 공유 DB (실시간) | 역할에 따라 가능 |
| GitHub Pages (`index.html`) | `events.json` 읽기 전용 | 불가 (개인 일정만 가능) |

GitHub Pages에서 팀 일정을 바꾸려면 `events.json`을 수정해 커밋하세요.

## 파일

- `index.html` — 앱 전체 (HTML/CSS/JS 단일 파일, 엠블럼 이미지 내장)
- `events.json` — GitHub Pages용 팀 일정 데이터
